2. Clone, Scaffold & Compile Locally (For All Viewers)

Run in terminal to scaffold the folders or compile programs on your PC

# A. Clone this repository or scaffold all 11 course directories locally:
git clone https://github.com/Ankit-DevLog/BCA-Coursework-.git
cd BCA-Coursework-
mkdir -p {Sem-01/{101PR-Programming-in-C,103PR-PC-Software-MS-Office},Sem-02/{201PR-Data-Structures-in-C,203PR-Web-Technologies},Sem-03/{301PR-OOP-Using-CPP,303PR-DBMS-SQL-PLSQL},Sem-04/{401PR-Computer-Graphics,403PR-VB-NET},Sem-05/501PR-Java-Programming,Sem-06/601PR-Web-Application-Development,Sem-07/701PR-AI-and-Python-Programming}

# B. Local Compiler Commands by Subject:
gcc 01_rotate_values.c -o app && ./app            # Sem I & II: ANSI C & Data Structures
g++ 01_basic_cin_cout.cpp -o app && ./app         # Sem III: C++ OOP
javac SimpleConsoleApp.java && java SimpleConsoleApp # Sem V: Java Programming
python3 03_a_star_algorithm.py                    # Sem VII: AI & Python 3
sbcl --script 01_lisp_list_and_recursion.lisp     # Sem VII: Common LISP
